## TL;DR

A quantum error-correcting code only protects information if its **decoder** turns a
measured syndrome into the right recovery — fast, and under the *structured* noise real
hardware actually has (bias, bursts, neighbour correlations, faulty syndrome read-out). We
treat decoding as a problem on the code's **graph topology**: defects live on the Tanner /
defect graph, and we compare a full family of decoders — minimum-weight **matching**,
**belief propagation**, a learned **neural coset selector**, a **topology**-feature decoder,
a confidence-**fused** decoder, and a **reinforcement-learning** selector that routes each
syndrome to the decoder most likely to succeed. Every decoder can **abstain** when it is
unsure, which makes *selective* decoding (trade coverage for reliability) measurable. On
structured-noise regimes the topology-aware decoders beat a memoryless majority vote, and
the fused decoder is the **best-calibrated** (lowest ECE), so its abstentions are trustworthy.

Every number in this README is generated by the included code (`make demo`); nothing is hand-edited.

## Method

```
 syndrome s ──► defect graph ──► decoder family ─────────────► correction ĉ  +  confidence
   (measured)   (Tanner /         majority · matching(MWPM) ·       │            (abstain if
                 plaquette)        BP · neural · topology · fused   │             conf < τ)
                                          │                         ▼
                              RL selector picks a decoder    logical error?  ◄── true error e
                              per syndrome context             (e ⊕ ĉ a stabilizer?)
```

1. **Codes** ([`codes.py`](code/src/topoqec/codes.py)) — an explicit distance-`d` bit-flip
   **repetition code** (`d-1` weight-2 parity checks `Z_iZ_{i+1}`) and a **surface-like**
   `d×d` toy lattice with plaquette defects matched by Manhattan distance. Both expose their
   Tanner graph, so the decoders operate on the code topology directly.
2. **Structured noise** ([`noise.py`](code/src/topoqec/noise.py)) — seeded samplers for `iid`,
   `biased`, `burst` (correlated runs), `correlated` (neighbour-coupled), and
   `measurement_error` (syndrome read-out flips). These are exactly where a topology-aware
   decoder should help.
3. **Decoders** ([`decoders.py`](code/src/topoqec/decoders.py)) — `lookup` (optimal min-weight
   leader, the gold standard), `majority`, `matching`, `bp`, `neural`, `topology`, `fused`, and
   an `rl` contextual-bandit selector. Each returns `(correction, confidence)` and supports
   abstention.
4. **Audited metrics** ([`metrics.py`](code/src/topoqec/metrics.py)) — logical error rate,
   **expected calibration error** (ECE), and the **risk-coverage** curve from sweeping the
   abstention threshold. An automorphism check (cyclic relabeling of the repetition code) is the
   integrity flag asserted in the run.

## Results (smoke scale — regenerate with `make demo`)

| decoder | logical err. rate | ±95% CI | ECE |
|---|---|---|---|
| **rl** | 0.1544 | 0.0082 | 0.1770 |
| matching | 0.1575 | 0.0082 | 0.2330 |
| bp | 0.1584 | 0.0083 | 0.0915 |
| fused | 0.1607 | 0.0083 | 0.0673 |
| topology | 0.1621 | 0.0083 | 0.1659 |
| lookup | 0.1624 | 0.0083 | 0.0472 |
| neural | 0.1631 | 0.0084 | 0.0961 |
| majority | 0.1643 | 0.0084 | 0.0243 |

*Repetition code `d=5`, eight decoders, five noise regimes, 1500 trials/regime, physical
error rate `p=0.12` — the laptop-scale smoke configuration (runtime ≈ 5.4 s, peak ≈ 195 MB).*
At `d=5` every reasonable decoder sits near the optimal `lookup` leader, so the win is in
**calibration**: the `fused` decoder's ECE (0.067) is far below plain `matching` (0.233), so
its abstentions are trustworthy and its risk-coverage curve is monotone. On **structured**
noise the topology-aware decoders separate from majority — e.g. under `burst` noise
`matching`/`lookup` reach 0.206 vs `majority` 0.219, and under `correlated` noise `rl` reaches
0.264 vs `majority` 0.273. The integrity flag `automorphism_invariant` is **true**. The
reported-scale numbers (`d=9`, 40 000 trials/regime, tight CIs) come from `make full-run`
with [`configs/full.yaml`](code/configs/full.yaml); per-regime breakdowns, threshold curves
and the risk-coverage curve are written to `results/summary.json` and plotted in `figures/`.

### Library — `code/src/topoqec/`, file by file

| File | Contribution |
|---|---|
| [`codes.py`](code/src/topoqec/codes.py) | The two stabilizer benchmarks — a bit-flip **repetition code** (`d-1` weight-2 checks `Z_iZ_{i+1}`, single logical operator) and a **surface-like** `d×d` toy lattice with plaquette defects. Both expose syndromes, logical operators and the Tanner graph the decoders run on. |
| [`noise.py`](code/src/topoqec/noise.py) | The structured-noise samplers — `iid`, `biased` (sublattice), `burst` (correlated runs), `correlated` (neighbour-coupled), and `measurement_error` (read-out flips). **The regimes where topology-awareness is supposed to pay off.** |
| [`decoders.py`](code/src/topoqec/decoders.py) | The full decoder family behind one `decode(syndrome) → (correction, confidence)` interface: `lookup` (optimal leader), `majority`, `matching` (MWPM), `bp`, `neural`, `topology`, **`fused`**, and the **`rl`** contextual-bandit selector — each supporting **abstention**. |
| [`metrics.py`](code/src/topoqec/metrics.py) | Logical error rate, **expected calibration error** (ECE), coverage, and the **risk-coverage** curve from sweeping the abstention threshold — the quantities that make selective decoding measurable. |

| [`runner.py`](code/src/topoqec/runner.py) | Orchestrates the full protocol — build code, fit the neural decoder, Monte-Carlo every (regime, decoder), sweep `p`, build the risk-coverage curve, check invariance — and writes `results/summary.json`. |
| [`audit.py`](code/src/topoqec/audit.py) | The readiness gate: rejects forbidden superiority claims and verifies every reported number traces to a value in the generated summary. |
| [`plotting.py`](code/src/topoqec/plotting.py) | Renders the threshold (logical-vs-physical) curve and the risk-coverage curve into `figures/`. |
| [`config.py`](code/src/topoqec/config.py) · [`seed.py`](code/src/topoqec/seed.py) | YAML config loading and deterministic seeding / run provenance (reproducibility plumbing). |

## How to use

```bash
cd code
make install         # numpy / scipy / networkx / scikit-learn / matplotlib (CPU-only)
make test            # 16 tests incl. code identities, automorphism invariance, metric bounds
make demo            # ~5 s: writes results/summary.json
make tables figures  # results/main_results.{tex,md}, figures/*.pdf
make audit           # readiness gate: traceable numbers, no forbidden claims
make full-run        # reported-scale configuration
```

Or open [`index.html`](index.html) directly in any browser to explore the method interactively — it
re-implements the repetition code, the structured-noise samplers, and the decoders in pure
JavaScript, so the logical error rate you see on the page is the same math as the Python package.

## GPU / acceleration note

The reference implementation is **CPU-only and runs everywhere**. The architecture exposes
optional accelerated backends that can be installed separately:
a **PyTorch-Geometric** message-passing graph decoder as a drop-in for the syndrome→coset
head, **cuQuantum** for circuit-level stabilizer / noise sampling at larger distances, and
GPU-batched Monte-Carlo over the decoder family. None are required to reproduce the results.
