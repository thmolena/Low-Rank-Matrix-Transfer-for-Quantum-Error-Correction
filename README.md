## Summary

A quantum error-correcting code protects information only insofar as its **decoder** maps a
measured syndrome to a correct recovery, quickly and under the *structured* noise that
hardware exhibits: bias, bursts, neighbour correlations, and faulty syndrome read-out.
Prevailing decoder benchmarks collapse decoding quality onto raw logical error under
independent and identically distributed (i.i.d.) noise, leaving two deployment-critical
quantities unmeasured: when a decoder should abstain, and whether its stated confidence is
trustworthy. This artifact builds a unified, reproducible benchmark that promotes
**selectivity** and **calibration** to first-class metrics. Decoding is treated as a problem
on the code's **graph topology**: defects live on the Tanner / defect graph, and a single
`decode(syndrome) → (correction, confidence)` interface hosts a full decoder family —
minimum-weight perfect **matching** (MWPM), **belief propagation** (BP), a learned **neural**
coset selector, a **topology**-feature decoder, a confidence-**fused** decoder, a
**reinforcement-learning** (RL) selector that routes each syndrome to a member decoder, an
optimal min-weight **lookup** leader, and a memoryless **majority** baseline. Every decoder
exposes an abstention threshold, which renders *selective* decoding (trading coverage for
reliability) measurable. The benchmark reports three quantities jointly — logical error rate
with analytic confidence intervals, expected calibration error (ECE), and the risk–coverage
curve — across five structured-noise regimes, and reports exactly what the run produces. At
reported scale the eight decoders are **statistically tied** on raw logical error rate, while
their calibration diverges roughly eight-fold; the separable, reproducible findings concern
calibration and the selective trade-off rather than accuracy.

Every number in this document is generated by the included code and traces to a single
source-of-truth artifact.

## Principal contributions

1. **One evaluation surface, three coupled metrics.** For a stabilizer code with parity-check
   map and logical functional, a family of structured-noise samplers, and a family of
   decoders sharing one `decode(s) → (ĉ, C)` interface, every (regime, decoder) pair is
   scored on a single defect-graph interface for logical error rate (with analytic 95%
   Bernoulli intervals), calibration (ECE), and the selective risk–coverage trade-off.
2. **Selectivity and calibration as first-class metrics.** Selective classification and the
   reject option are transplanted into the decoding setting and made measurable per decoder,
   accompanied by a decision-theoretic monotonicity property linking risk–coverage to
   calibration.
3. **Structured-noise coverage.** The same decoder family is evaluated across five regimes —
   `iid`, `biased`, `burst`, `correlated`, and `measurement_error` — with statistical
   significance reported explicitly for every comparison, rather than under i.i.d. noise
   alone.
4. **Integrity enforced in code.** A cyclic-relabeling automorphism-invariance check guards
   the symmetry assumptions, and an audit gate rejects any reported number that fails to trace
   to the single source-of-truth artifact and rejects absolute-superiority phrasing, executed
   in continuous integration.

## Headline results

At reported scale (distance `d = 9`, eight decoders, five noise regimes, 40,000 trials per
regime, `n = 200,000` shots aggregated per decoder, physical error rate `p = 0.12`), the
logical error rates lie within one confidence-interval width of one another: the spread of
0.0024 across decoders is below one interval width (≈ 0.0032), so the decoders are
**statistically tied** on raw logical error. Calibration tells a separate story: ECE spans
0.0317–0.2608, an eight-fold range that varies independently of decoder complexity.

*Repetition code `d = 9`; eight decoders; five structured-noise regimes (`iid`, `biased`,
`burst`, `correlated`, `measurement_error`); 40,000 trials per regime; `n = 200,000` shots
per decoder; `p = 0.12`. The reported run completes end-to-end in 507 s at 200.5 MB peak
memory on a single CPU (provenance recorded in `code/results/summary.json`: macOS-26.5.1-arm64,
Python 3.13.12, numpy 2.4.3, scipy 1.17.1, networkx 3.6.1, scikit-learn 1.8.0, matplotlib
3.10.8, master seed 0).* The logical error rates span 0.1516–0.1540 with a 95% interval
half-width of 0.0016; the 0.0024 spread is sampling fluctuation, consistent with the
statistical tie. The integrity flag `automorphism_invariant` is **true**. Across the
eleven-point physical-error grid under i.i.d. noise every core decoder tracks the optimal
`lookup` leader and remains below the break-even line `p_L = p`; at `p = 0.21` the logical
error is ≈ 0.024–0.025 for every core decoder, and the curves overlap throughout. Sweeping
the abstention threshold yields large, monotone reliability gains: the `fused` decoder's
risk–coverage curve descends from 0.1516 logical error at full coverage toward 0.010 at
≈ 0.25 coverage. The reported-scale numbers come from `make full-run` with
[`code/configs/full.yaml`](code/configs/full.yaml); the laptop-scale `make demo`
configuration ([`code/configs/smoke.yaml`](code/configs/smoke.yaml)) regenerates a smaller
distance-5 run in a few seconds. Per-regime breakdowns, threshold curves, and the
risk–coverage curve are written to `code/results/summary.json` and plotted in `code/figures/`.

## Method

```
 syndrome s ──► defect graph ──► decoder family ─────────────► correction ĉ  +  confidence
   (measured)   (Tanner /         majority · matching(MWPM) ·       │            (abstain if
                 plaquette)        BP · neural · topology · fused   │             conf < τ)
                                          │                         ▼
                              RL selector picks a decoder    logical error?  ◄── true error e
                              per syndrome context             (e ⊕ ĉ a stabilizer?)
```

1. **Codes** ([`codes.py`](code/src/topoqec/codes.py)) — an explicit distance-`d` bit-flip
   **repetition code** (`d-1` weight-2 parity checks `Z_iZ_{i+1}`) and a **surface-like**
   `d×d` toy lattice with plaquette defects matched by Manhattan distance. Both expose their
   Tanner graph, so the decoders operate on the code topology directly.
2. **Structured noise** ([`noise.py`](code/src/topoqec/noise.py)) — seeded samplers for `iid`,
   `biased`, `burst` (correlated runs), `correlated` (neighbour-coupled), and
   `measurement_error` (syndrome read-out flips), the regimes where topology-awareness is
   expected to matter.
3. **Decoders** ([`decoders.py`](code/src/topoqec/decoders.py)) — `lookup` (optimal min-weight
   leader, the reference oracle), `majority`, `matching` (MWPM), `bp`, `neural`, `topology`,
   `fused`, and an `rl` contextual-bandit selector. Each returns `(correction, confidence)`
   and supports abstention.
4. **Audited metrics** ([`metrics.py`](code/src/topoqec/metrics.py)) — logical error rate,
   **expected calibration error** (ECE), and the **risk–coverage** curve obtained by sweeping
   the abstention threshold. A cyclic-relabeling automorphism check on the repetition code
   supplies the integrity flag asserted in each run.

## Installation

```bash
pip install topoqec
```

For a source checkout with the reproducibility pipeline:

```bash
cd code
pip install -e .            # core deps: numpy / scipy / networkx / scikit-learn / matplotlib / pyyaml
# pip install -e .[gpu]     # optional accelerated backend (torch)
```

## Reproduction

The installed console entry point deterministically regenerates the tables and figures:

```bash
topoqec-reproduce --config configs/full.yaml     # reported-scale tables + figures
topoqec-reproduce --config configs/smoke.yaml    # laptop-scale demo
```

Equivalently, from the source tree:

```bash
cd code
make install         # core dependencies (CPU-only)
make test            # tests: code identities, automorphism invariance, metric bounds
make demo            # ~6 s: writes results/summary.json (smoke scale)
make tables figures  # results/main_results.{tex,md}, figures/*.pdf
make audit           # readiness gate: traceable numbers, forbidden phrasing rejected
make full-run        # reported-scale configuration
```

The [`index.html`](index.html) demo re-implements the repetition code, the structured-noise
samplers, and the decoders in pure JavaScript, so the logical error rate shown on the page
follows the same mechanism as the Python package.

## GPU / acceleration note

The reference implementation is CPU-only and portable. The architecture exposes optional
accelerated backends installable separately: a PyTorch-Geometric message-passing graph
decoder as a drop-in for the syndrome→coset head, cuQuantum for circuit-level stabilizer /
noise sampling at larger distances, and GPU-batched Monte-Carlo over the decoder family. The
reported results are reproduced without any of them.
