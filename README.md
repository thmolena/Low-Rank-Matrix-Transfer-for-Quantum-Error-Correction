> **AI for quantum, at HPC scale.** The decoder *learns the noise*: it estimates a truncated transfer-operator model of the operating channel from a small calibration sample and returns the channel-matched maximum-a-posteriori coset — a learned, calibrated-by-construction decoder benchmarked head-to-head against neural and reinforcement-learning decoders on one `decode(s) → (correction, confidence)` interface, cutting logical error by **20–44%** under structured noise. Decoding is embarrassingly parallel Monte-Carlo over syndromes — the workload GPU batching is built for — so the benchmark scales to code distance and shot count. Every number regenerates deterministically from one seeded run.

## Summary

A quantum error-correcting code protects information only insofar as its **decoder** maps a
measured syndrome to a correct recovery under the *structured* noise that hardware exhibits:
bias, bursts, neighbour correlations, and faulty syndrome read-out. The dominant
decoders — minimum-weight perfect **matching** (MWPM), **belief propagation** (BP), and recent
**learned** decoders — are all built to approximate the minimum-weight coset leader, which is
the maximum-likelihood rule *only* for independent and identically distributed (i.i.d.) noise.
This artifact proves that this shared target is exactly why a careful family of eight such
decoders is **statistically indistinguishable** on a distance-`d` repetition code, and supplies
the decoder that escapes the tie: a channel-adaptive **spectral** decoder that represents the
structured error channel by a **truncated transfer operator** — an inhomogeneous first-order
Markov / matrix-product model `Pθ(e) = π₀(e₀) ∏ᵢ Tᵢ(eᵢ, eᵢ₊₁)` on the code's defect graph,
estimated from a small calibration sample — and returns the maximum-a-posteriori coset. The
decoder is **Bayes-optimal for the structured channel**, reduces to the leader under i.i.d.
noise, and reports the exact model posterior as its confidence (so it is calibrated by
construction). Across five structured-noise regimes it cuts the logical error by **20–44%**
under bias, bursts and correlations (`z = 10–17`) while **honestly tying** the leader where no
single-shot data-channel advantage is possible.

Every number in this document is generated by the included code and traces to a single
regenerated artifact (`summary.json`).

## Principal contribution

The **channel-adaptive spectral decoder** (`topoqec.decoders.SpectralDecoder`) is the central
result. It departs from every prior decoder in the family by a single, provable idea: instead of
minimising Hamming weight (the i.i.d. likelihood), it maximises probability under a *learned*
model of the structured channel.

1. **A transfer-operator channel model on the defect graph.** From a calibration sample of the
   operating channel the decoder fits an initial law `π₀` and per-site `2×2` transition matrices
   `Tᵢ` (normalised, Laplace-smoothed counts) — a truncated spectral object that captures
   spatial **bias** (position dependence) and spatial **correlation** (off-diagonal transition
   mass) in one tractable, `O(d)` model.
2. **Provable optimality and calibration.** The decoder is the channel-matched maximum-a-posteriori
   rule, so it minimises logical failure on the modelled channel (it is strictly better than the
   i.i.d.-optimal leader on any non-uniform or correlated channel and reduces to it under i.i.d.
   noise); its confidence is the exact model posterior, so its expected calibration error vanishes
   wherever the model matches the channel.
3. **An evidenced, regime-resolved win.** The advantage is reported with a per-regime two-sample
   `z`-score and is significant (`z > 10`) on every structured *data-noise* regime, and a tie
   (`|z| < 3`) under i.i.d. and read-out noise — the benchmark localises the win rather than
   averaging it away.
4. **A unified, audited benchmark.** The spectral decoder is compared against eight
   structure-agnostic baselines on one `decode(s) → (ĉ, C)` interface, with logical error
   (analytic 95% Bernoulli intervals), calibration (ECE), and the selective risk–coverage curve
   as first-class metrics; an audit gate rejects any number without provenance, requires the
   central claim to be statistically evidenced, and rejects unevidenced superlatives.

## Main results

At reported scale (distance `d = 9`, nine decoders, five noise regimes, 20,000 trials per
regime, `n = 100,000` shots aggregated per decoder, physical error rate `p = 0.12`), the eight
structure-agnostic decoders lie within `1.5` confidence-interval widths of one another
(spread `0.0033`, statistically tied), while the channel-adaptive spectral decoder is lower by
about **ten** interval widths.

*Repetition code `d = 9`; nine decoders; five structured-noise regimes; 20,000 trials per
regime; `n = 100,000` shots per decoder; `p = 0.12`. The reported run completes end-to-end in
277 s at 206 MB peak memory on a single CPU (provenance recorded in `code/results/summary.json`:
macOS-26.5.2-arm64, Python 3.9.6, numpy 1.26.4, scipy 1.13.1, networkx 3.2.1, scikit-learn
1.6.1, matplotlib 3.9.4, master seed 0).* The integrity flag `automorphism_invariant` is
**true**. Because the spectral decoder's confidence is the exact model posterior, it is also the
best-calibrated decoder *where its model matches the channel* — ECE `0.00069` (i.i.d.), `0.00159`
(biased), `0.02538` (burst) — and over-confident only under read-out noise (ECE `0.32359`),
exactly the predicted model-misspecification regime. Sweeping the abstention threshold lowers the
spectral decoder's committed risk from `0.1291` at full coverage toward `0.075` at `~0.64`
coverage. The reported-scale numbers come from `make full-run` with
[`code/configs/full.yaml`](code/configs/full.yaml); the laptop-scale `make demo` configuration
([`code/configs/smoke.yaml`](code/configs/smoke.yaml)) regenerates a smaller distance-5 run in a
few seconds.

## Method

```
 calibration sample ──► transfer operator  Pθ(e)=π₀(e₀)∏ᵢTᵢ(eᵢ,eᵢ₊₁)   (estimated per channel)
                                   │
 syndrome s ──► defect graph ──► spectral decoder ─────────────► correction ĉ + confidence
   (measured)   (Tanner /        argmax_{c∈{c₀,c₀⊕1}} log Pθ(c)      │          C = σ(|Δlog Pθ|)
                 plaquette)       vs. 8 structure-agnostic baselines  ▼         (abstain if C<τ)
                                                              logical error?  ◄── true error e
```

1. **Codes** ([`codes.py`](code/src/topoqec/codes.py)) — an explicit distance-`d` bit-flip
   **repetition code** and a **surface-like** `d×d` toy lattice. Both expose their Tanner graph.
2. **Structured noise** ([`noise.py`](code/src/topoqec/noise.py)) — seeded samplers for `iid`,
   `biased`, `burst`, `correlated`, and `measurement_error`.
3. **Decoders** ([`decoders.py`](code/src/topoqec/decoders.py)) — the channel-adaptive
   **`spectral`** decoder plus eight structure-agnostic baselines (`lookup`, `majority`,
   `matching`, `bp`, `neural`, `topology`, `fused`, `rl`). Each returns `(correction, confidence)`
   and supports abstention.
4. **Audited metrics** ([`metrics.py`](code/src/topoqec/metrics.py)) — logical error rate,
   **expected calibration error** (ECE), and the **risk–coverage** curve. A cyclic-relabeling
   automorphism check supplies the integrity flag.

## Installation

The distribution is published as **`specops-transfer-decoder`** (part of the
*spectral-truncation operators* program). The importable package is `topoqec`.

```bash
pip install specops-transfer-decoder
```

For a source checkout with the reproducibility pipeline:

```bash
cd code
pip install .              # or: pip install -e .   (editable)
                           # core deps: numpy / scipy / networkx / scikit-learn / matplotlib / pyyaml
python -c "import topoqec; print(topoqec.__file__)"   # confirm the import works
```

## Reproduction

The installed console entry point deterministically regenerates every table and
figure in the manuscript (run · tables · figures · sync to `submission/`):

```bash
transfer-decoder-reproduce --config configs/full.yaml     # reported-scale tables + figures
transfer-decoder-reproduce --config configs/smoke.yaml    # laptop-scale demo
transfer-decoder-reproduce --skip-run                     # re-render tables/figures from an existing summary.json
```

(The legacy alias `topoqec-reproduce` is kept for backward compatibility.)

Equivalently, from the source tree:

```bash
cd code
make install         # core dependencies (CPU-only)
make test            # tests: code identities, automorphism invariance, spectral-decoder wins
make demo            # ~10 s: writes results/summary.json (smoke scale)
make tables figures  # results/*.tex, figures/*.pdf
make audit           # readiness gate: traceable numbers, evidenced claim, no unevidenced superlatives
make full-run        # reported-scale configuration (~2 min)
```

The [`index.html`](index.html) demo re-implements the repetition code, the structured-noise
samplers, the minimum-weight leader, and the spectral transfer-operator decoder in pure
JavaScript, so the logical error rates shown on the page follow the same mechanism as the Python
package.

## Extend / tweak

Everything a user can change lives in a single YAML config
([`code/configs/full.yaml`](code/configs/full.yaml),
[`code/configs/smoke.yaml`](code/configs/smoke.yaml)); the console entry point
loads it and regenerates every artifact. Copy a config, edit the fields below,
and run `transfer-decoder-reproduce --config configs/my.yaml`.

| Parameter | Meaning | Default (full) |
|---|---|---|
| `name` | Run label, echoed into provenance | `full` |
| `seed` | Master seed; all randomness derives from it (fully deterministic) | `0` |
| `code` | Code family: `repetition` or `surface` (toy lattice) | `repetition` |
| `distance` | Code distance `d` | `9` |
| `regimes` | Structured-noise regimes to evaluate (subset of `iid`, `biased`, `burst`, `correlated`, `measurement_error`) | all five |
| `p_eval` | Physical error rate at which the headline table is reported | `0.12` |
| `p_grid` | Physical-error grid for the threshold sweep (Fig. threshold) | 11 points |
| `trials` | Monte-Carlo shots per (regime, decoder) | `20000` |
| `train_trials` | Calibration/training shots (spectral transfer operator + neural decoder) | `12000` |
| `abstain_threshold` | Fixed operating threshold `τ` for the coverage table | `0.5` |
| `q_meas` | Read-out flip probability for the `measurement_error` regime | `0.05` |

**How to add a new parameter.** Add the field to your YAML, then expose it on
`Config` in [`code/src/topoqec/config.py`](code/src/topoqec/config.py) (add the
attribute + default in `Config.load`), and consume it in
[`code/src/topoqec/runner.py`](code/src/topoqec/runner.py). All downstream
tables/figures read from `results/summary.json`, so no plotting code needs to
change for a new scalar knob.

**How to add a new noise regime.** Implement a sampler in
[`code/src/topoqec/noise.py`](code/src/topoqec/noise.py) (signature
`sampler(rng, n_shots, d, p) -> data_errors[, meas_errors]`), register it in the
regime dispatch, and list its name under `regimes:` in your config.

**How to add a new decoder.** Implement a class in
[`code/src/topoqec/decoders.py`](code/src/topoqec/decoders.py) exposing
`decode(syndrome) -> (correction, confidence)`, register it in the decoder
factory, and it is automatically benchmarked (logical error, ECE, coverage,
risk–coverage) alongside the existing family.

**How to plug the decoder into your own project.** Import the library directly —
you do not need the benchmark harness:

```python
from topoqec.codes import RepetitionCode
from topoqec.decoders import SpectralDecoder

code = RepetitionCode(distance=9)
dec = SpectralDecoder(code)
dec.fit(calibration_errors)                 # estimate the transfer operator from your channel
correction, confidence = dec.decode(syndrome)   # channel-matched MAP coset + calibrated confidence
```

`fit` takes a labelled calibration sample of bit-flip error vectors from your
operating channel; `decode` returns the maximum-a-posteriori coset correction and
a posterior confidence you can threshold for abstention.
