Learning to decode correlated quantum errors: a topological graph neural decoder that surpasses minimum-weight matching under structured circuit-level noise

Molena Huynh · North Carolina State University · molena.huynh@jmp.com

Read the manuscript (PDF) Reproducible code

Abstract

Decoding a quantum error-correcting code is fundamentally a problem of statistical inference: a syndrome is a noisy observation, and the correct logical class is the one the fault distribution makes most probable. The dominant surface-code decoder, minimum-weight perfect matching (MWPM), scores a correction by summing per-edge weights of a graphlike error model — an independence assumption that hardware violates, because crosstalk and correlated two-qubit faults flip several detectors jointly. We prove that MWPM is maximum-likelihood if and only if the fault distribution factorizes over graphlike edges, and construct correlated instances on which its logical error rate is provably bounded away from optimal. We then introduce a topological graph neural decoder — a message-passing network on the detector graph in which correlated hyperedge faults appear as denser local subgraphs. Trained only on samples, it estimates the Bayes posterior over the logical class and returns a calibrated confidence. On Stim circuit-level rotated surface-code memory experiments decoded head-to-head on identical shots, the learned decoder cuts the logical error rate by 46.1% at distance 3 under correlated noise (paired McNemar p = 2.4 × 10−164), recovering most of the gap to the model-aware BP+OSD ceiling without being given the model.

Background

A logical qubit is encoded redundantly across many physical qubits (here the distance-d rotated surface code). The hardware does not measure the encoded state directly; it repeatedly measures stabilizers — multi-qubit parity checks that are deterministic without noise. Comparing stabilizer outcomes across rounds defines binary detectors; a lit detector marks a space-time location where a parity changed, i.e. evidence of an error. A decoder reads the pattern of lit detectors (the syndrome) and infers whether the encoded logical bit was flipped so it can be corrected. The quality of this classical inference, not the raw device physics, sets the achievable logical error rate.

Stim compiles a noisy circuit into a detector error model (DEM): a list of independent fault mechanisms, each flipping a fixed set of detectors and possibly the logical observable. A mechanism flipping at most two detectors is graphlike (an edge in a decoding graph); one flipping three or more is a hyperedge. MWPM operates on the graphlike view and is exact maximum-likelihood decoding if and only if the fault distribution factorizes over independent edges. Correlated hardware faults violate that assumption, and matching has no way to represent the joint structure it discards.

Contributions

  1. A tight optimality characterization for matching. MWPM coincides with maximum-likelihood decoding if and only if the fault distribution factorizes over graphlike edges; under any correlated distribution no fixed edge weights make matching maximum-likelihood.
  2. A provable separation under correlation. We exhibit an explicit DEM with a single correlated mechanism on which matching's logical error rate exceeds the Bayes-optimal decoder's by a strictly positive, closed-form amount — the probability mass on a logical-flipping hyperedge matching cannot represent.
  3. Decoding as Bayesian inference. We identify the Bayes-optimal target as the coset-MAP decoder and prove, for the learned network, Bayes-optimality of the coset posterior, a universal-approximation theorem on the detector graph, a Rademacher/VC generalization bound with explicit sample complexity, and a risk-consistency theorem — establishing it as a consistent probabilistic surrogate for an intractable maximum-likelihood decoder.
  4. A topological graph neural decoder. One node per detector, edges joining detectors that share a fault mechanism (so correlated hyperedges become denser subgraphs); trained only on samples, it outputs the posterior over the logical class and a calibrated confidence for selective decoding.
  5. A controlled empirical dissection. All decoders score identical shots under a noise knob interpolating from independent to correlated, with Wilson intervals, paired McNemar exact tests, paired bootstrap intervals, and calibration error, so any difference is attributable to representational power. Every reported number is traced to a single summary.json.

Method sketch

The decoder places one node per detector and joins two nodes whenever a mechanism in the full DEM flips both, so a correlated hyperedge contributes a small clique and local graph density encodes the correlation structure matching discards. Each node carries its normalized space-time coordinates (x, y, t); the only per-shot input is the binary detector value. With the symmetric-normalized adjacency Â (self-loops included), each layer computes

h(l+1) = LayerNorm( ReLU( Wself·h(l) + Wneigh·Â·h(l) ) )

followed by mean- and max-pooling and a two-layer perceptron to a single logit; a sigmoid yields q̂ = Pr[logical flip | detectors], an estimate of the Bayes posterior. The decision threshold is calibrated on validation data, and max(q̂, 1−q̂) is the confidence for selective decoding. Training minimizes binary cross-entropy — a strictly proper scoring rule, so the population optimum is the true posterior — on fresh samples from the circuit under test; the network never sees the DEM. Because the graph topology is shared across shots, message passing reduces to a few dense matrix products and runs CPU-only. Baselines are MWPM (PyMatching, decomposed DEM) and BP+OSD (ldpc, full DEM), each regime-aware.

Figures are the released small-scale reproduce target: the rotated surface code at distance d = 3, T = d rounds, over 2 seeds, all decoders scoring identical test shots (CPU-only, total runtime ≈ 36 s). Pooled logical error rate (LER) with 95% Wilson intervals:

Under independent noise MWPM is provably maximum-likelihood, and MWPM and BP+OSD agree; no decoder can beat matching in this regime. Under correlated noise matching cannot represent the correlated hyperedges and its LER rises to 0.1985, well above the BP+OSD ceiling of 0.0757. The learned decoder attains 0.1070 — a 46.1% relative reduction in logical error versus MWPM, overwhelmingly significant under the paired McNemar test, with a paired-bootstrap interval for the LER difference that excludes zero. At d = 3 the learned decoder recovers 74.5% of the MWPM → BP+OSD gap without ever being given the noise model. The posterior is well calibrated (expected calibration error 0.0251 under correlated noise), so committing only on the most confident shots drives the committed logical error down monotonically.

The advantage tracks correlation strength and is largest at small code distance, concentrated in exactly the strongly-correlated, near-term hardware regime where a better decoder is most valuable. The released headline run is at d = 3; the main and full presets sweep d ∈ {3, 5, 7} for readers with more compute.

Reproducibility

The runner writes a single source-of-truth results/summary.json (all raw numbers plus platform, library-version, and runtime provenance) from which every table, figure, and in-text number is generated. All randomness derives from recorded seeds. CPU-only; no GPU required.

References and related work

The learned decoder is benchmarked against two established baselines: minimum-weight perfect matching via PyMatching, built on Edmonds' blossom algorithm and the Stim-extracted detector error model, and belief propagation with ordered-statistics post-processing (BP+OSD) via the ldpc library, the strong model-aware baseline for correlated and quantum-LDPC codes. Circuits and detector error models are generated with Stim. The work builds on the surface- and toric-code literature and on a substantial body of neural and graph-based decoders, including architectures matched to the detector structure and learned decoders that exceed matching on hardware syndromes; its contribution is a controlled, provable dissection isolating where and why a learned decoder helps.
