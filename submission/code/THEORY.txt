================================================================================
THEORY.txt  --  Selective & calibrated decoding for quantum error correction
A from-scratch derivation of every concept the code in this folder implements.
================================================================================

This document is meant to be read top-to-bottom by someone who has seen linear
algebra and basic probability but NOT quantum error correction, stabilizer
codes, minimum-weight matching, belief propagation, calibration, or selective
prediction. Every symbol used in the code is defined. Each section maps to a
source file so you can read theory and implementation side by side.

--------------------------------------------------------------------------------
0. THE PROBLEM IN ONE PARAGRAPH
--------------------------------------------------------------------------------
A quantum error-correcting (QEC) code stores one logical bit redundantly across
many physical bits. Noise flips some physical bits; we are not allowed to look
at the bits directly (that would destroy the quantum state), so instead we
measure a few parity checks whose outcomes form a SYNDROME. A DECODER takes the
syndrome and guesses a correction. It succeeds if (correction XOR error) is a
"do-nothing" operator (a stabilizer); it fails if that residual flips the
logical bit. The usual figure of merit is the LOGICAL ERROR RATE. This project
argues that two further axes matter just as much and are usually ignored:
(i) SELECTIVE DECODING -- letting the decoder ABSTAIN when unsure, so a slower
fallback can take over; and (ii) CALIBRATION -- whether the decoder's stated
confidence actually matches how often it is right. We build one benchmark that
measures all three (logical error, calibration, risk-coverage) for eight
decoders across five STRUCTURED-noise regimes, with honest 95% confidence
intervals. The deliberately conservative headline: on this code the eight
decoders are statistically TIED on raw logical error, but they differ sharply in
calibration and in the reliability that abstention buys.

--------------------------------------------------------------------------------
1. CODES, SYNDROMES, AND LOGICAL FAILURE              [src/topoqec/codes.py]
--------------------------------------------------------------------------------
REPETITION CODE (RepetitionCode). The primary benchmark. A logical bit is
encoded in d data bits over F_2 = {0,1} (the field of integers mod 2; XOR is
"+"). The code has d-1 weight-two parity checks of the form Z_i Z_{i+1}. An
error is a vector e in F_2^d (e_i = 1 means data bit i is flipped). The syndrome
of e is
        s_i = e_i XOR e_{i+1},   i = 0 .. d-2.                  [.syndrome()]
Intuition: s_i fires exactly where an error CHAIN crosses link i, so the lit
syndrome bits sit at the ENDPOINTS of error chains. Decoding is therefore a
matching/pairing problem on a one-dimensional line of links.

The single LOGICAL OBSERVABLE is the global parity L(e) = (sum_i e_i) mod 2
[.logical_value()]. A correction c-hat is a LOGICAL FAILURE [.logical_error()]
unless the residual r = e XOR c-hat (a) reproduces zero syndrome (r is a
stabilizer, i.e. it acts trivially) AND (b) has zero logical value. A correction
that does not even reproduce the measured syndrome is automatically a failure.
This is the exact definition of "the code protected the bit".

LOOKUP TABLE. For small d we can enumerate all 2^d errors [.all_errors()] and,
for every syndrome, store the minimum-weight error that produces it -- the
"coset leader". This optimal table is the gold-standard decoder for small d and
the yardstick everything else is compared against (Section 4, LookupDecoder).

SURFACE-LIKE CODE (SurfaceLikeCode). A second, two-dimensional code: d*d data
bits on a grid with (d-1)^2 weight-four plaquette checks; a lit plaquette is a
DEFECT, and defects are paired by Manhattan (L1) distance. Logical observable =
parity of the left column. It exposes the SAME defect geometry in 2-D so the
matching/topology decoders generalize, but it is a topology-FAITHFUL toy, NOT a
stabilizer-exact CSS surface code -- we say so honestly. Both codes expose a
bipartite Tanner graph via networkx [.tanner_graph()] so graph-based decoders
operate on the code topology directly.

--------------------------------------------------------------------------------
2. STRUCTURED NOISE (why i.i.d. is not enough)        [src/topoqec/noise.py]
--------------------------------------------------------------------------------
Real hardware noise is NOT independent-and-identically-distributed. Five seeded
samplers, each taking a numpy Generator and returning a 0/1 error vector, model
the structure that matters [noise.sample() dispatches on the regime name]:
  iid                : each bit flips independently with prob p. [sample_iid]
  biased             : even-index bits flip at min(1, bias*p), odd-index at p
                       (default bias=3) -- a coarse Pauli-bias surrogate. [sample_biased]
  burst              : scanning the line, with prob p flip a contiguous run of
                       length 1+Poisson(burst_len-1) (default burst_len=3) --
                       spatially clustered errors. [sample_burst]
  correlated         : an i.i.d. seed pattern recruits each neighbour with prob
                       corr (default 0.5) over two sweeps -- neighbour
                       correlations. [sample_correlated]
  measurement_error  : i.i.d. data noise at rate p PLUS a per-check syndrome
                       read-out flip mask at rate q (default 0.05); the runner
                       XORs that mask into the MEASURED syndrome, so the decoder
                       conditions on a corrupted signal. [sample_measurement_error]
These are precisely the regimes where topology- or read-out-aware decoding might
beat a memoryless majority vote -- and the regimes turn out to dominate the
difficulty far more than the choice of decoder (Section 8).

--------------------------------------------------------------------------------
3. WHAT A DECODER RETURNS (the unified interface)  [src/topoqec/decoders.py]
--------------------------------------------------------------------------------
EVERY decoder implements one interface:
        decode(syndrome) -> (correction, confidence),
with correction in F_2^n and confidence in [0,1]. The single interface is what
makes the eight decoders comparable on one footing and what makes abstention
(Section 6) and calibration (Section 7) definable uniformly. Helpers:
_chain_from_defects() turns a set of paired defect endpoints into a flip chain;
_defect_confidence(n_def, n_checks) = exp(-2 n_def / n_checks) is the
defect-fraction confidence heuristic (more lit checks -> less sure).

--------------------------------------------------------------------------------
4. THE DECODER FAMILY (textbook to learned)           [decoders.py]
--------------------------------------------------------------------------------
  LookupDecoder    : the optimal min-weight coset leader from the enumerated
                     table; confidence boosted toward 1 since the leader is exact.
                     The gold standard for small d.
  MajorityDecoder  : cumulative XOR (prefix sum mod 2) of the syndrome recovers a
                     flip chain up to a global offset; pick the lower-weight of
                     the two cosets; confidence is the normalized majority margin.
  MatchingDecoder  : MINIMUM-WEIGHT PERFECT MATCHING of defects. On the line,
                     pair lit syndrome bits left-to-right (with a boundary
                     closure for an odd count) and return the lighter coset. On
                     the surface, build a complete graph on lit plaquettes
                     weighted by NEGATIVE Manhattan distance and call networkx
                     max_weight_matching (Edmonds' blossom algorithm), then flip
                     an L-shaped path between matched pairs. Confidence is the
                     defect-fraction heuristic, damped when a defect is unpaired.
                     This is the standard surface-code decoder, in toy form.
  BPDecoder        : a few rounds of min-sum BELIEF PROPAGATION (message passing)
                     on the Tanner graph with log-likelihood priors; if the
                     thresholded beliefs do not reproduce the syndrome, DEFER to
                     matching. (BP underpins quantum LDPC decoding.)
  NeuralDecoder    : a LEARNED two-stage coset selector. Stage 1: a
                     syndrome-determined base chain (always syndrome-consistent).
                     Stage 2: a scikit-learn LogisticRegression that predicts the
                     LOGICAL COSET (0/1) of the true correction relative to that
                     base chain. The output is therefore always syndrome-valid
                     and the confidence is the predicted-class probability --
                     which is exactly why it tends to be well calibrated
                     (Section 7). It is fit on a mixed-regime training stream.
  TopologyDecoder  : matching, but with confidence RECALIBRATED by defect-
                     geometry features (count, span, gap structure).
  FusedDecoder     : matching and neural both propose; agreement boosts
                     confidence, disagreement defers to the more confident
                     proposal with damped confidence (confidence fusion).
  RLDecoder        : a CONTEXTUAL BANDIT (reinforcement learning). Context = a
                     coarse defect-count bucket; actions = candidate decoders. It
                     keeps per-context running success estimates, plays
                     epsilon-greedy during a warm-up stream, and at evaluation
                     picks the highest-value decoder per context.
build_decoders() wires the family together for a given code.

--------------------------------------------------------------------------------
5. METRIC 1 -- LOGICAL ERROR RATE AND HONEST INTERVALS [src/topoqec/metrics.py]
--------------------------------------------------------------------------------
For each (regime, decoder) we Monte-Carlo many shots and record a per-shot
failure indicator F in {0,1}. The logical error rate is p-hat = mean(F)
[logical_error_rate()]. Because F is BERNOULLI, its sample std is
s = sqrt(p-hat(1-p-hat)) and a 95% confidence interval half-width is
        ci95 = 1.96 * s / sqrt(n)                               [summarize()]
with n the number of shots. THIS IS THE WHOLE POINT OF HONESTY: two decoders
whose means differ by LESS than a CI width are NOT separated at 95%. At reported
scale (n = 200,000 pooled shots) the eight decoders span only 0.1516..0.1540
with ci95 ~ 0.0016, so the 0.0024 best-to-worst spread is below one interval
width -> the decoders are statistically TIED. We report the tie, not a winner.

--------------------------------------------------------------------------------
6. METRIC 2 -- SELECTIVE DECODING AND THE RISK-COVERAGE CURVE  [metrics.py]
--------------------------------------------------------------------------------
A decoder inside a fault-tolerant loop need not commit to every syndrome: it can
ABSTAIN (flag a shot unreliable) so a fallback handles it. This is the QEC
analogue of SELECTIVE PREDICTION in machine learning. Fix a confidence
threshold tau and commit only on shots with confidence >= tau. Then:
   COVERAGE(tau) = fraction of shots committed,
   RISK(tau)     = logical error rate ON THE COMMITTED shots.
Sweeping tau from the smallest to the largest observed confidence traces the
RISK-COVERAGE CURVE [risk_coverage_curve()], reported in descending-coverage
order. As we abstain more (coverage shrinks), risk should fall: we drop the
shots we were least sure about. is_monotone_risk_coverage() programmatically
verifies risk is (weakly) non-increasing as coverage shrinks. Empirically the
effect is large: matching's committed error falls from 0.1529 at full coverage
to 0.0758 at ~0.55 coverage and 0.0099 at ~0.25 coverage.

WHY CALIBRATION GATES THIS (the theorem in the paper, Sec. "Theory"). Suppose
the confidence C is perfectly CALIBRATED, meaning Pr(success | C=c) = c. Then on
committed shots Pr(failure | C >= tau) = 1 - E[C | C >= tau]. Raising tau keeps
only the upper tail of C, whose conditional mean can only increase, so the
committed RISK can only DECREASE. That is the formal reason abstention works --
but ONLY to the extent that confidence is calibrated. Hence Section 7.

--------------------------------------------------------------------------------
7. METRIC 3 -- CALIBRATION (Expected Calibration Error)        [metrics.py]
--------------------------------------------------------------------------------
A confidence score is only useful for abstention if it is HONEST about its own
accuracy. EXPECTED CALIBRATION ERROR [expected_calibration_error()] partitions
the shots into 10 equal-width confidence bins; within each bin it compares the
MEAN STATED CONFIDENCE to the MEAN REALIZED ACCURACY (= 1 - failure), takes the
absolute gap, and averages those gaps weighted by bin occupancy:
        ECE = sum_bins (n_bin / n) * | mean_conf(bin) - mean_acc(bin) |.
ECE = 0 means "when the decoder says 0.8, it is right 80% of the time". The
paper's most counterintuitive finding lives here: across the family ECE spans an
EIGHT-FOLD range (0.0317 .. 0.2608) and is UNCORRELATED with sophistication. The
best calibrated is the lightweight NEURAL selector (its confidence is literally a
predicted-class probability, Section 4); the WORST is plain MATCHING (its
defect-fraction heuristic tracks accuracy poorly). Calibration must be MEASURED,
not assumed from accuracy or complexity. (This even contradicts the project's own
README intuition that "fused" is best calibrated -- we report the artifact's
number, fused ranks fourth at 0.0608, not the intuition.)

--------------------------------------------------------------------------------
8. STRUCTURED NOISE SEPARATES REGIMES, NOT DECODERS    [runner.by_regime]
--------------------------------------------------------------------------------
The per-(regime, decoder) breakdown shows the DOMINANT axis of variation is the
NOISE REGIME, not the decoder. Logical error rises ~100-fold from ~0.002 (iid)
to ~0.043 (biased), ~0.17 (burst), ~0.21 (correlated), ~0.34 (measurement error,
the hardest -- read-out flips corrupt the very signal decoders condition on).
Within each regime the decoders again cluster inside their (now tight) CIs, while
COVERAGE varies strongly: matching/topology/RL abstain heavily under structure,
whereas majority/lookup/neural/fused commit fully.

--------------------------------------------------------------------------------
9. INTEGRITY: AUTOMORPHISM INVARIANCE + AUDIT GATE
                                  [src/topoqec/symmetry.py, audit.py]
--------------------------------------------------------------------------------
AUTOMORPHISM INVARIANCE. The repetition code is invariant under CYCLIC
relabeling of its data bits (a ring symmetry). cyclic_relabel(error, shift)
rotates an error; logical_error_rate_under_relabeling() and
is_automorphism_invariant() check that the matching decoder yields the SAME
logical error rate on rotated errors (over shifts {1, 2, d/2}, within a
statistical tolerance). A faithful decoder must respect the code's symmetry; the
run exposes this as the automorphism_invariant integrity flag (true at scale).

AUDIT GATE. audit.py enforces scientific hygiene: audit_numbers() checks every
CLAIMED number traces to a value in the generated summary.json (the single
source of truth); audit_reproducibility_phrase() checks the mandated
reproducibility statement is present; audit_forbidden_claims() rejects forbidden
absolute-superiority phrasing. scripts/audit_claims.py runs these in CI and exits
non-zero on any violation -- so the paper CANNOT drift from the artifact.

--------------------------------------------------------------------------------
10. THE SINGLE SOURCE OF TRUTH AND HOW TO REPRODUCE   [src/topoqec/runner.py]
--------------------------------------------------------------------------------
runner.run() ties it all together: build the code; fit the neural decoder on a
mixed-regime training stream; warm up the RL bandit on its own Monte-Carlo
stream; for each (regime, decoder) Monte-Carlo `trials` shots at p_eval and
record per-shot failure/confidence; sweep p over a grid (iid) for the threshold
curves; build the risk-coverage curve from the fused and matching confidences;
check automorphism invariance. It writes results/summary.json -- the SINGLE
SOURCE OF TRUTH from which every table, figure and reported number is generated.
Nothing is typed by hand. Then:
  scripts/make_tables.py  : summary.json -> results/main_results.tex (booktabs)
  scripts/make_figures.py : summary.json -> figures/{fig_schematic, fig_threshold,
                            fig_risk_coverage}.pdf, in Nature Machine Intelligence
                            house style (vector PDF, pdf.fonttype=42, sans-serif
                            with mathtext dejavusans, colour-blind-safe Okabe-Ito
                            palette, no in-plot titles, despined, 95% CI bands).
  scripts/audit_claims.py : the readiness gate of Section 9.

To reproduce everything:
  pip install -r requirements.txt && pip install -e .
  export KMP_DUPLICATE_LIB_OK=TRUE          # pip-torch + conda libomp on macOS
  bash scripts/reproduce_all.sh full        # reported scale (d=9, 40k trials/regime)
  bash scripts/reproduce_all.sh             # fast smoke config for CI (d=5)
Reported run: repetition code, distance 9, five regimes, 40,000 trials/regime
(200,000 pooled shots/decoder), 20,000 training shots, p_eval=0.12, seed 0. The
figure/table artifacts are copied verbatim into submission/ to build the paper.

--------------------------------------------------------------------------------
11. WHAT THE RESULT MEANS (and what it does NOT)
--------------------------------------------------------------------------------
The eight decoders are statistically INDISTINGUISHABLE on raw logical error for a
distance-d repetition code in these regimes -- as expected, since every
reasonable decoder is close to the optimal coset leader and finite-sample noise
dominates the residual gaps. We therefore make NO accuracy-superiority claim. The
genuine, separable contributions are: (i) the framework -- a whole decoder family
on one defect-graph interface under structured noise with honest CIs; (ii)
selective decoding -- abstention cuts committed logical error several-fold for a
moderate coverage cost; and (iii) calibration as a first-class metric -- ECE
spans 8x and is decoupled from sophistication. Limitations are stated plainly:
toy codes only (repetition code; surface-LIKE toy, not a stabilizer-exact surface
code), SIMULATED structured noise (not hardware syndromes), differences within
noise on raw error, a single distance, lightweight learned models, and a single
author/environment. Extending to a full surface code at scale, to hardware
syndromes, and to a distance-scaling (sub-threshold) study -- while keeping
selectivity and calibration first-class -- is the natural next step.
